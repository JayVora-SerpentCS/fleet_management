Detailed Features

🚘 Extended Vehicle Registration & Master Data

Register vehicles with enhanced fields beyond the standard fleet module, including specifications, ownership details, fuel type, operational status, and classification—ensuring accurate and structured vehicle records.

🛠️ Structured Service Order Management

Create detailed vehicle service orders with service types, vendors, stages, costs, and repair details. Track the complete maintenance lifecycle from service creation to completion with full traceability.

⏱️ Semi-Automated Odometer Logging

Automatically generate odometer logs during services or operations while allowing manual entries when needed, ensuring mileage accuracy without restricting flexibility.

🔄 Vehicle Component Change History

Maintain historical records for critical components such as tyres, batteries, engines, and color updates. Each change is logged and linked to service records for complete transparency.

❌ Vehicle Write-Off & Damage Documentation

Write off vehicles with comprehensive details including write-off reason, damaged parts, required repairs, estimated costs, and supporting images for audit and compliance purposes.

📊 Operational Reports & Fleet Insights

Access built-in reports that provide insights into service costs, vehicle usage, maintenance frequency, and overall fleet performance to support informed decision-making.

Screenshots

Vehicle Registration Lifecycle Management with Kanban Workflow

Path:- Fleet → Vehicles Registration

Manage vehicle onboarding using a kanban workflow with stages like New Request, To Order, Ordered, Registered, and Reserve, providing clear visibility into the vehicle registration status.

Centralized Fleet Menu Navigation

Path :-  Fleet → Vehicles Registration / Fleet Driver / Vehicles Write-off / Vehicle Services / Odometers

Access all fleet-related operations from a single menu, including vehicle registration, driver management, services, write-offs, and odometer tracking for smooth fleet administration.

Detailed Vehicle Profile & Lifecycle Control

Path :- Fleet → Vehicles Registration → Open Vehicle

View and manage complete vehicle details including make, model, driver assignment, registration data, ownership, and current lifecycle state with quick action buttons for services, write-off, and component updates.

Engine Specifications & Technical Configuration

Path :-Fleet → Vehicles Registration → Open Vehicle → Engine Specifications

Record and manage detailed engine parameters such as engine number, transmission type, horsepower, emissions, cylinders, and taxation details, ensuring accurate technical documentation for each vehicle.

Vehicle Quick Stats Panel

Path :- Fleet Management → Vehicle Overview → Vehicle Details

This panel provides a quick overview of a vehicle’s key information:

  • Drivers History: Displays the number of drivers who have operated the vehicle.
  • Services: Shows the count of maintenance or service records for the vehicle.
  • Odometer: Indicates the number of odometer readings or updates recorded.
Vehicle History Tab – Fleet Management

Path :- Fleet > Vehicles Registration > [Vehicle Name] > History Tab

This screenshot shows the History tab of a vehicle record in the Fleet module. It highlights the historical changes for a specific vehicle, including Engine History and Color History, along with change dates and linked work orders. The top section of the form displays general vehicle details such as registration number, odometer reading, and status. Action buttons like Update Engine, Update Color, and Services are also visible.

Update Vehicle Color Information

Path :- Fleet / Workshop → Work Order → Update Color Info (Popup/Wizard)

This screen allows the user to update the vehicle’s color for a specific work order. It displays the previous color, the newly selected color, and the change date. The user can also add notes related to the color change. Once confirmed, the update button applies the changes, while the cancel button discards them.

Vehicle Odometer Records

Path :-  Fleet → Vehicles Registration → [Vehicle Name] → Odometers

This screen displays the list of odometer readings recorded for a specific vehicle. It shows details such as the date of the reading, vehicle name, assigned driver, odometer value, and unit of measurement (km). Users can track the vehicle’s usage history, monitor mileage updates, and add new odometer entries using the New button.

Vehicle Service Order Details

Path :- Fleet → Vehicles Registration → [Vehicle Name] → Services → [Service Order]

This screen shows the detailed information of a vehicle service order, including vehicle details, service type, odometer readings, service dates, workshop, and total cost. Users can manage the service status, create invoices, track deliveries, and view related repairs, parts, attachments, and notes.

Vehicle Services List

Path :- Fleet → Vehicles Registration → [Vehicle Name] → Services

This screen displays the list of all service records for a selected vehicle. It shows details like work order number, service type, purchaser, vendor, cost, and status, allowing users to easily track and manage vehicle service history.

Vehicle Write-Off Details

Path :- Fleet → Vehicles Registration → [Vehicle Name] → Write-Off → [Write-Off Record]

This screen shows the detailed information of a vehicle write-off record, including vehicle details, odometer, driver, write-off type, and repair expenses. It also allows users to select damaged areas, repair types, and add supporting notes or pictures for proper documentation.

Fleet XLSX Report Export

Path :- Fleet → Vehicles Registration → Select Vehicle(s) → Actions → Fleet xlsx Report

This option allows users to export selected vehicle records into an XLSX (Excel) report for easy viewing, sharing, and offline analysis.

Fleet XLSX Report Wizard

Path :- Fleet → Vehicles Registration → Select Vehicle(s) → Actions → Fleet xlsx Report

This popup allows users to select a specific fleet report type (such as history, listing, pending repairs, completed stage, or next service details) and generate it in XLSX format for download and analysis.
